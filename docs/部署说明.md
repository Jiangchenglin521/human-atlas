# 人体图谱 3D 部署说明

纯前端静态站点，部署在网站根路径。构建产物在 `dist/`，不需要后端、数据库或 AI 接口。

## 本地开发

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev
```

开发地址：<http://localhost:3016/>

## 生产打包

```sh
npm run build
```

产物目录：`dist/`。其中包含 `index.html`、脚本样式，以及 `models/` 下的解剖目录和分片模型。

## 部署到 Vercel

仓库已包含 `vercel.json`：安装用 `npm ci`，构建用 `npm run build`，输出目录是 `dist`。Node.js 使用 22。

1. 把这个项目推到你自己的 Git 仓库（不要推回上游 `ashemag/human-atlas`）。
2. 在 Vercel 选择 Import Git Repository，框架选 Vite。
3. 部署完成后打开 `https://项目名.vercel.app/`。

页面资源从网站根路径加载。用 Git 连接再构建，不要用 Vercel CLI 直接上传整个目录：Hobby 计划的 CLI 源码上传上限是 100MB，模型文件会超过这个体积。
